## Merovio CRM

A MERN stack AI powered CRM application.

### Installation

```bash
git clone git@github.com:MehulBawadia/merovio-crm.git

# For Backend
cd merovio-crm/backend
cp .env.example .env
npm install
npm run dev

# For Frontend
cd merovio-crm/frontend
cp .env.example .env
npm install
npm run dev
```
